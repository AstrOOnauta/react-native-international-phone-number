# Contributing

Contributions are very welcome.

1. Fork or clone this repository:

   ```bash
   git clone https://github.com/AstrOOnauta/react-native-international-phone-number.git
   ```

2. Repair, update and enjoy 🛠️🚧⚙️

3. Open a pull request to the [main repo](https://github.com/AstrOOnauta/react-native-international-phone-number).
